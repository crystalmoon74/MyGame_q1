 ## 회고

아래 PRD를 작성 후 진행했으며 AI가 생성 전에 몇 가지 조건과 문제점에 대해 확인 요청이 와 추가 조건 확인 후 진행했습니다. 
기획 단계에서는 괜찮은 아이디어로 보였으나 실제로 게임을 생성해 보니 온라인으로 진행하기에 500 피스 직소 게임은 좀 부담스러운 듯 합니다. 


### PRD
 MyGame_Q1 폴더에 안에 아래 게임을 만들고 git에 올려서 외부에서 접속할 수 있도록 만들어 줘.

1.만들 게임: 500 피스 직소 게임 
2.규칙: 
1) 500 피스 직소 게임
2) 6가지 유형 제공해 주고 1가지를 선택해서 시작할 수 있도록 해줘. 난이도를 중 3개, 상 3개로 분리해 줘.
3) 감동을 주었던 유명 영화의 한장면 들이면 좋을 것 같아.
4) 제한 시간은 없어도 돼.
5) 피스를 다 맞추면 완료.
끝나는 조건: [예: 5판 승부 / 기회 10번 소진 / 제한시간 30초]

파일은 index.html, styles.css, script.js 세 개로 나눠줘.
- 모바일에서도 조작하기 편한 크기로, [내 게임의 상태]가
  색과 문구로 함께 보이게 해줘.
- 내가 적은 규칙 그대로 동작하고, 끝나는 조건이 되면
  결과와 다시하기 버튼이 나오게 해줘.

규칙에 애매한 부분이 있으면 만들기 전에 나에게 물어봐.
완료 후 내가 브라우저에서 확인할 방법과 수정 체크리스트를 알려줘.
