# 🧩 AIFFEL 나만의 게임 과제 제출

## 🎮 게임 소개

**500피스 직소 퍼즐 게임 (500-Piece Jigsaw Puzzle)**

감동을 주었던 유명 영화의 명장면을 테마로 한 온라인 직소 퍼즐 게임입니다.

- **게임 플레이:** [MyGame Q1 바로가기](https://crystalmoon74.github.io/MyGame_q1/)
- **개발 방식:** AI를 활용한 PRD 기반 게임 개발
- **사용 기술:** HTML, CSS, JavaScript
- **배포 환경:** GitHub Pages

---

## 📋 PRD (Product Requirements Document)

AI에게 아래 요구사항을 전달하여 게임 개발을 요청했습니다.

### 1. 프로젝트 목표

`MyGame_Q1` 폴더에 500피스 직소 퍼즐 게임을 개발하고, GitHub에 업로드하여 외부에서도 웹브라우저로 접속할 수 있도록 구현합니다.

### 2. 게임 요구사항

| 구분 | 요구사항 |
|---|---|
| 게임 유형 | 500피스 직소 퍼즐 |
| 퍼즐 종류 | 총 6가지 |
| 난이도 | 중 3개, 상 3개 |
| 이미지 테마 | 감동을 주었던 유명 영화의 명장면 |
| 게임 방식 | 6가지 퍼즐 중 하나를 선택하여 시작 |
| 제한 시간 | 없음 |
| 완료 조건 | 500개 퍼즐 조각을 모두 맞추면 완료 |
| 게임 종료 | 퍼즐 완성 시 결과 표시 및 다시하기 제공 |

### 3. 개발 및 UI 요구사항

**파일 구조**

```text
MyGame_Q1/
├── index.html
├── styles.css
└── script.js
```

**세부 요구사항**

1. HTML, CSS, JavaScript를 각각 별도 파일로 구성합니다.
2. 모바일에서도 조작하기 편한 UI를 제공합니다.
3. 게임 진행 상태를 색상과 문구로 함께 표시합니다.
4. PRD에 정의한 게임 규칙이 정상적으로 동작해야 합니다.
5. 게임 완료 시 결과 화면과 다시하기 버튼을 제공합니다.
6. 요구사항에 모호한 부분이 있다면 개발 전에 사용자에게 확인합니다.
7. 개발 완료 후 브라우저에서 테스트하는 방법과 수정 체크리스트를 제공합니다.

## 🤖 AI의 요구사항 확인 및 추가 결정

PRD를 전달한 후 AI가 개발을 시작하기 전에 몇 가지 모호한 조건과 잠재적인 문제점을 확인해 주었습니다.

AI가 제안한 권장 사항을 검토한 후 아래와 같이 최종 결정했습니다.

| 확인 항목 | AI의 질문 및 제안 | 최종 결정 |
|---|---|---|
| 게임 종료 조건 | 종료 조건이 명확하지 않음 | 500피스 완성 시 종료 |
| 난이도 구분 | 모든 퍼즐이 500피스인데 난이도를 어떻게 구분할 것인가? | 상 난이도에 피스 회전 기능 추가 |
| 이미지 저작권 | 실제 영화 스틸컷을 공개 사이트에 사용하는 경우 저작권 문제 발생 가능 | 영화 명장면 오마주 일러스트 사용 |
| 외부 배포 | GitHub Pages를 이용한 무료 웹 배포 제안 | GitHub Pages 사용 |

### 주요 결정 사항

**1. 게임 종료 조건**

제한 시간이나 시도 횟수에 대한 제약 없이 500개의 퍼즐 조각을 모두 맞추면 게임이 완료되도록 결정했습니다.

게임 진행 상태는 `맞춘 피스 수 / 500` 및 진행률(%)로 표시합니다.

**2. 난이도 구분**

모든 퍼즐의 조각 수는 동일하게 500개로 유지하되, 난이도에 따라 조작 방식을 다르게 설정했습니다.

- **중:** 기본 직소 퍼즐
- **상:** 퍼즐 조각 회전 기능 추가

**3. 이미지 저작권 고려**

유명 영화의 실제 스틸컷 대신 영화의 분위기와 명장면에서 영감을 얻은 오마주 일러스트를 사용하도록 결정했습니다.

**4. GitHub Pages 배포**

별도의 웹 서버를 구축하지 않고 GitHub Pages를 통해 게임을 공개하도록 결정했습니다.

## ✍️ 프로젝트 회고

### 1. 기획 및 개발 과정

이번 과제에서는 먼저 PRD를 작성하고, 이를 기반으로 AI에게 게임 개발을 요청했습니다.

AI는 곧바로 코드를 생성하기보다 요구사항 중 모호하거나 추가 결정이 필요한 부분을 먼저 질문했습니다.

특히 게임 종료 조건, 난이도 구분, 이미지 저작권, 배포 방식에 대해 확인을 요청했고, AI가 제안한 권장 사항을 검토하여 추가 조건을 확정한 후 개발을 진행했습니다.

이 과정을 통해 **AI를 활용한 개발에서도 요구사항을 명확하게 정의하고, 개발 전에 모호한 부분을 해결하는 과정이 중요하다**는 것을 경험했습니다.

### 2. 아쉬웠던 점

기획 단계에서는 500피스 직소 퍼즐이 적절한 난이도와 재미를 제공할 수 있을 것으로 생각했습니다.

하지만 실제로 게임을 생성해 보니 온라인 환경에서 500개의 조각을 마우스나 터치로 조작하는 방식은 생각보다 부담스러웠습니다.

특히 다음과 같은 부분에서 개선이 필요하다고 느꼈습니다.

- 500개의 조각을 화면에 배치하고 구분하는 데 어려움이 있음
- 퍼즐 완성까지 시간이 오래 걸려 사용자에게 피로감을 줄 수 있음
- 모바일과 같이 화면이 작은 환경에서는 조작이 더욱 어려울 수 있음
- 난이도뿐 아니라 사용자의 편의성과 게임 몰입도도 고려할 필요가 있음

### 3. 배운 점

이번 프로젝트를 통해 다음과 같은 점을 배웠습니다.

1. **PRD의 중요성:** AI가 원하는 결과물을 생성하려면 요구사항이 구체적이고 명확해야 합니다.
2. **AI와의 협업:** AI가 제시하는 질문과 대안을 검토하면서 초기 기획의 부족한 부분을 보완할 수 있습니다.
3. **사용자 경험(UX)의 중요성:** 기능적으로 구현할 수 있는 게임이라고 해서 반드시 플레이하기 좋은 게임이 되는 것은 아닙니다.
4. **프로토타입 검증의 필요성:** 본격적인 개발 전에 작은 규모로 구현하고 실제 사용성을 검증하는 과정이 필요합니다.

### 4. 향후 개선 방향

다음 버전에서는 아래 사항을 고려해 보고자 합니다.

- 100피스, 300피스, 500피스 등 조각 수 선택 기능 제공
- 퍼즐 조각 정렬 및 힌트 기능 추가
- 모바일 환경에 적합한 조작 방식 개선
- 단순한 퍼즐 맞추기를 넘어 새로운 게임 요소 도입

## 💡 마무리

이번 과제는 AI를 활용하여 아이디어를 실제 웹 게임으로 구현해 보는 경험이었습니다.

기획 당시에는 괜찮은 아이디어라고 생각했지만, 실제 결과물을 확인하면서 **개발 가능성과 사용자 경험은 별개의 문제**라는 점을 알게 되었습니다.

또한 AI가 코드를 생성하는 것만큼이나, 사람이 요구사항을 정의하고 결과물을 검증하며 개선 방향을 판단하는 역할이 중요하다는 것을 느꼈습니다.

다음 프로젝트에서는 처음부터 큰 규모로 구현하기보다는 작은 프로토타입을 먼저 만들고, 실제 플레이 경험을 확인하면서 점진적으로 개선해 보고자 합니다.
